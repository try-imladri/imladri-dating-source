This is a disclosed Imladri static OpenSSL backport, not an upstream PyPI wheel. The native binary was independently reproduced byte-for-byte and passed the recorded upstream suites. Sources, licenses, five exact upstream patches, Cargo.lock and producer toolchain inventories are included. Use rebuild.py --output with a new task directory and the recorded immutable toolchain image; Dockerfile.toolchain documents its construction. Compilation and tests run without networking after cargo fetch --locked. The recipe refuses a mismatched native binary. Production image, role and provider verification remain separate release gates.
